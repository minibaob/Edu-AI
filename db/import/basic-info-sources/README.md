## 可达性口径（2026-11-20 复核）

- 200–399、403：可达。
- 412：高校站点 WAF 对非浏览器客户端的反爬挑战响应（curl 可见挑战页 JS、TLS 证书校验通过，
  如兰州大学/北京邮电大学/北京电影学院官网）。视为可达，缓存记 `'412'`，CSV 备注注明
  「招生网址实测返回412（站点WAF反爬挑战响应，TLS证书校验通过）」。自动化浏览器亦可能被
  挑战拦截，故不声称已用浏览器逐站打开；真实用户浏览器通常可正常通过挑战。
- 证书不受信任、连接失败、超时：不可达，留空并注明。
- 旧缓存中 false 条目在每次运行时重测（true/'412' 保留），避免历史误判沉淀。
