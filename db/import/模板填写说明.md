# 模块5 高校与录取数据 · 导入模板填写说明

首批试点省份：**河北、河南**。所有数据必须来自官方公开渠道；**不得编造任何高校或录取数据**。
填不到的字段留空，网站对应位置显示「暂无数据」。每条记录的「数据来源」必填（渠道名称 + 页面/文件标题 + 整理日期）。

## 使用方法

1. 复制 `templates/` 下四个 CSV 到你的工作目录（不要改表头、不要增删列）。
2. 用 Excel / WPS 打开填写（模板带 UTF-8 BOM，中文不乱码）；保存时保持 **CSV UTF-8** 格式。
3. 运行校验：`node db/import/validate.mjs <你的目录>`，按提示修正到 0 错误。
4. 入库（二选一）：
   - 生成入库 SQL：`node db/import/to-sql.mjs <你的目录> [输出文件]`（先校验，不通过不生成；重复执行安全）。把生成的 SQL 交给平台审核迁移流程应用；浏览器不直接写数据库。
   - 或走网站导入：校验通过后交给导入工具（网站「数据导入」页，管理员账号登录后可见）入库；浏览器不直接写数据库。
5. 已有按本模板列结构整理的 XLSX（如河南.xlsx，含「录取数据」「招生计划」两表及学校名称列）时，
可用 `npm i --no-save xlsx && node dev/convert-henan.mjs <xlsx路径> <输出目录>` 直接转换为四个 CSV
（xlsx 仅为本地转换工具依赖，不进入项目依赖与 Function 包）。转换只搬运原值，不修改任何数据。

## universities.csv（高校基础信息）

| 列 | 必填 | 规则 |
| --- | --- | --- |
| 院校代码 | 是 | 官方院校代码，全表唯一 |
| 学校名称 | 是 | 官方全称，全表唯一 |
| 所在省份 | 否 | 31 省份之一（学校所在地，非招生省份）；官方文件未提供时留空 |
| 所在城市 | 否 | 文本 |
| 办学类型 | 否 | 综合/理工/农林/医药/师范/语言/财经/政法/体育/艺术/军事/其他 |
| 办学层次 | 否 | 本科/专科 |
| 标签 | 否 | 双一流/985/211/公办/民办/中外合作，多个用 `\|` 分隔 |
| 招生网址 | 否 | https:// 开头的官方招生网网址 |
| 数据来源 | 是 | 官方渠道标注 |
| 备注 | 否 | 文本 |

## majors.csv（专业信息）

| 列 | 必填 | 规则 |
| --- | --- | --- |
| 专业代码 | 是 | 教育部专业目录代码，4–6 位数字，全表唯一 |
| 专业名称 | 是 | 目录规范名称 |
| 学科门类 | 是 | 哲学/经济学/法学/教育学/文学/历史学/理学/工学/农学/医学/军事学/管理学/艺术学/交叉学科 |
| 学制 | 是 | 2–8 的整数（年） |
| 授予学位 | 否 | 学士/第二学士/硕士/博士 |
| 数据来源 | 是 | 官方渠道标注 |
| 备注 | 否 | 文本 |

## admission_scores.csv（历年录取数据）

| 列 | 必填 | 规则 |
| --- | --- | --- |
| 院校代码 | 是 | 必须已在 universities.csv 登记 |
| 省份 | 是 | 河北/河南（试点） |
| 年份 | 是 | 2000–当前年份 的整数 |
| 科类 | 是 | 物理类/历史类/理科/文科/综合/艺术类/体育类 |
| 批次 | 是 | 官方批次名称，如 本科批、本科一批、本科二批、专科批、本科提前批 |
| 选科要求 | 否 | 如「物理+化学」「不限」 |
| 最低分 | 否 | 0–750，最多两位小数（艺术/体育类综合分带小数，备注中说明口径） |
| 最低位次 | 否 | ≥1 整数 |
| 录取人数 | 否 | ≥0 整数 |
| 数据来源 | 是 | 官方渠道标注 |
| 备注 | 否 | 文本 |
| 学校名称 | 否 | 官方全称，便于人工核对 |

同一「院校+省份+年份+科类+批次」只能一行。分数/位次/人数可留空（显示暂无数据）。

## enrollment_plans.csv（招生计划）

| 列 | 必填 | 规则 |
| --- | --- | --- |
| 院校代码 | 是 | 招生计划中的院校代码（各省报考代码可能与录取表国标代码不同，保留原值） |
| 省份 | 是 | 河北/河南（试点） |
| 年份 | 是 | 2000–当前年份 的整数 |
| 专业代码 | 否 | majors.csv 有数据时必须已登记；majors.csv 为空时跳过该检查 |
| 专业名称 | 是 | 当年招生计划中的专业名称 |
| 批次 | 否 | 官方批次名称 |
| 选科要求 | 否 | 如「物理+化学」「不限」 |
| 计划数 | 否 | ≥0 整数 |
| 学费 | 否 | ≥0 整数（元/学年） |
| 数据来源 | 是 | 官方渠道标注 |
| 备注 | 否 | 文本（办学地点/合作方等官方说明原样保留） |
| 学校名称 | 是 | 官方全称，必须已在 universities.csv 登记；计划表与院校表按名称关联 |

同一「院校+省份+年份+专业+批次」出现多行时只警告（官方计划可能因办学地点/合作方不同而分行），数据原样保留。

## 官方来源渠道（示例，按实际公布页面标注）

- 河北省教育考试院、河南省教育考试院公布的历年录取分数统计/招生计划专刊。
- 阳光高考平台（教育部高校招生阳光工程指定平台）院校库与专业库。
- 各高校本科招生网公布的分省分专业录取分数与招生计划。
- 教育部《普通高等学校本科专业目录》（专业代码/门类/学制）。
