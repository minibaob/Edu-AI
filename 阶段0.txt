# 阶段0：EduAI 项目环境检查与技术方案

请使用 Qoder Agent 模式执行本阶段。

当前不要直接开发业务功能，也不要直接创建大量文件。

## 任务一：检查开发环境

请检查：
- 当前项目目录和已有文件。
- Windows 开发环境。
- Node.js 和包管理器版本。
- Git 是否正常。
- GitHub 仓库是否已经配置。
- 当前是否已经存在前端或后端项目。
- 是否存在可复用代码。

## 任务二：制定技术方案

根据我们的情况推荐合适技术：

- 两名大学生开发者。
- 编程经验有限。
- 希望借助 Qoder Agent 开发。
- 预计两周左右完成 MVP。
- 优先电脑网页端，同时兼容手机浏览器。
- 希望使用托管式数据库和认证服务，减少维护工作。
- 需要考虑中国大陆访问稳定性。

请比较适合的前端框架、数据库、认证方式、文件存储、部署方案。

可以评估 Next.js、Supabase 等方案，但不要未经分析直接确定。

请特别说明：
1. 各服务在中国大陆的访问情况。
2. 是否需要信用卡或付费。
3. 免费额度和限制。
4. 部署难度。
5. 数据安全与备份方式。
6. 两名初学者是否容易维护。

## 任务三：制定项目结构

给出建议的项目目录结构，并解释各目录用途。

## 任务四：制定开发计划

请根据两周左右的开发周期，安排后续开发顺序。

## 输出要求

本阶段只输出：
1. 环境检查报告。
2. 技术栈建议和优缺点。
3. 项目架构建议。
4. 项目目录结构。
5. 开发阶段安排。
6. 可能的技术风险。

暂时不要修改现有项目，不要安装依赖，不要执行部署。

等待我们确认技术方案后再开始下一阶段。
